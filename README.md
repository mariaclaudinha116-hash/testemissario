# Clone Missário - Fluxo Completo

Este repositório contém o clone estático do site Missário, incluindo o fluxo de:
- Home
- Loja
- Carrinho
- Checkout

## Estrutura
- `index.html`: Página inicial
- `loja.html`: Vitrine de produtos
- `cart-page.html`: Carrinho de compras
- `checkout.html`: Página de finalização (Pronta para integração de API de Pix)

## Como usar
Basta abrir o arquivo `index.html` em qualquer navegador ou fazer o deploy em serviços como GitHub Pages, Vercel ou Netlify.
